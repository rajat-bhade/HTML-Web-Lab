# Web Technology Lab - Experiment 1

Introduction to HTML5 Environment and Development of First Web Page.

## What this contains

- `index.html` - Student profile page built using basic HTML5 tags
- `css/style.css` - Basic styling
- `js/script.js` - Basic script
- `images/` - Put your photo here as `myphoto.jpg`

## Tags covered

Document structure (doctype, head, title, body), headings (h1-h6),
paragraph, formatting (bold, italic, underline, mark, small, sub, sup,
strong, em), ordered and unordered lists, image tag, anchor tag.

## How to run

1. Open the folder in VS Code
2. Install "Live Server" extension
3. Right click `index.html` -> "Open with Live Server"

OR simply double click `index.html` to open it in the browser.
