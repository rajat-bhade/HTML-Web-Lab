Margin vs Padding Challenge

BOX A
padding: 40px
margin: 10px
BOX B
padding: 10px
margin: 40px

Observation

  • Box A has more internal space (bigger padding pushes content away from border).
  • Box B has more external space (bigger margin pushes the box away from neighbours).
  • Changing margin does not move content inside the border, it only changes distance from other elements.
  • Changing padding does move the content, since it adds space between content and border.
